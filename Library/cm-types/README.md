# CM types (legacy format)

CM types are now **blueprints** in `../blueprints` (`apolloiq.blueprint/1`), made in the Blueprint editor. The old `apolloiq.cmtype/1` files are no longer part of the library; copies are kept only as test fixtures in `Builder.Tests/Legacy`.

The PriorityInputControl type is removed: input control is built into every CM as **command inputs** (see *4.9 Input control*).
